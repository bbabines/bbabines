# Brad Babines

### Frontend engineering · Real-time 3D · AI developer tools

I build interactive 3D applications and tools that help people create with them.

At **Rogue Fitness**, I’m the technical owner of **Rackbuilder**, our Three.js product-visualization platform. My work spans frontend architecture, rendering, asset optimization, testing, and production delivery.

I also created **Nightward MCP**, an Unreal Engine plugin that enables AI agents to make editor changes, verify the results, and recover when something goes wrong.

## What I own and build

* **Production 3D experiences:** TypeScript, Vue, React, and Three.js interfaces for exploring and configuring products.
* **Architecture and delivery:** Technical direction, coding standards, code review, and weekly production readiness across a 50+ microservice platform.
* **AI-assisted creative tools:** Unreal editor automation, agent tooling, verification workflows, and rollback.
* **Graphics and visual workflows:** PBR materials, Blender asset pipelines, and shader-driven visuals.

## Selected work

**Rogue Rackbuilder**
- Own the platform’s technical direction and architecture. Led frontend and 3D delivery for RM Cave 2.0, including an interactive measurement system.
